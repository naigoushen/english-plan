# 大一上学期英语学习计划

一个纯静态的打卡网页，用来跟踪这学期的英语学习进度。手机和电脑浏览器都能直接打开，不需要安装任何东西，也没有后端。

## 页面

- **今日**：今天第几周、星期几，今天的课，今天该做的英语任务，以及「完成今天的晨读」按钮。
- **打卡**：晨读打卡格子（可按周看，也可展开看整学期 17 周），以及 Unit 1 到 Unit 8 的五项单元进度。
- **计划**：整学期时间轴，自动标出「现在在这里」，下面接三条纪律和开学初期要做的三件事。
- **统计**：晨读完成率、连续晨读工作日、本周晨读、单元进度、距考试天数。

## 学期常量

这些值写在 `app.js` 顶部，学期变了改这里就行。

| 常量 | 值 | 含义 |
| --- | --- | --- |
| `WEEK1_MONDAY` | `2026-08-31` | 第 1 周的周一 |
| `CHECKIN_WEEKS` | `[3, 19]` | 晨读打卡覆盖的周次 |
| `TERM_START` | `2026-09-14` | 新生正式上课 |
| `EXAM_START` / `EXAM_END` | `2027-01-04` / `2027-01-10` | 第 19 周统考 |
| `MILITARY` | `2026-11-23` 到 `2026-12-06` | 军训 |

课表在 `COURSES`，每周任务在 `WEEK_PLAN`，时间轴在 `TIMELINE`，特殊日期在 `HOLIDAYS` 和 `DAY_NOTES`。

## 数据保存在哪

记录保存在浏览器本地，键名 `eng-plan.v1`。这意味着：

- 手机和电脑各记各的，不会自动同步；换设备或换浏览器时用页面右上角的「备份与恢复」搬。
- 清理浏览器数据、用无痕模式打开，记录都会丢。
- 用 `file://` 直接打开时，部分浏览器不允许本地存储，正式使用建议用线上网址。

## 本地预览

直接双击 `index.html` 即可。想看某一天的界面，在地址后面加 `?date=2027-01-04` 这样的参数。

## 部署到 GitHub Pages

1. 在 GitHub 新建一个公开仓库，名字用 `english-plan`，不要勾选初始化 README。
2. 把本目录的三个文件推送到 `main` 分支。
3. 进入仓库 Settings → Pages，Source 选 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`，保存。
4. 等一两分钟，访问 `https://<你的用户名>.github.io/english-plan/`。

在手机浏览器打开后，可以用「添加到主屏幕」当成一个应用。

## 更新部署

改完文件后重新提交并推送，GitHub Pages 会自动重新发布，一般一分钟内生效。手机上可能需要下拉刷新才能看到新版本。
